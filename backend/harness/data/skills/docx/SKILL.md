# 制作 Word 文档

## 什么时候用

用户要一份**能用 Word 打开、能继续编辑**的 `.docx`。只要 Markdown 本身不必走这套。

## 流程

1. **先写正文**，用 `write` 存成工作区里的 `.md`。结构参考 `workspace-report` 技能
   （结论 / 依据 / 细节 / 存疑），除非用户另有要求。
2. **生成**：
   ```
   bash("python3 .skills/docx/scripts/build_docx.py 正文.md 输出.docx")
   ```
   可选参数：
   - `--toc` 在正文前插入目录域（Word 打开后按 Ctrl+A、F9 刷新即显示）
   - `--page-numbers` 页脚居中页码
   - `--title "文档标题"` 写进文档属性

   需要用户批准后才会执行。
3. **读回核对**（二进制 `read` 看不了）：
   ```
   bash("python3 .skills/docx/scripts/read_docx.py 输出.docx --limit 3000")
   ```
   用 pandoc 转回 Markdown。内容长就加 `-o 回读.md` 写成文件再分段读。
4. **告诉用户文件名**，让他从右栏「文件」下载。

## 支持的 Markdown

| 写法 | 结果 |
|---|---|
| `#` ～ `####` | 一到四级标题 |
| 普通段落 | 正文 |
| `**粗体**` `*斜体*` `` `行内代码` `` | 对应格式，可混排 |
| `- 项` | 项目符号（缩进 2 格为二级） |
| `1. 项` | 编号列表 |
| `\| 分隔 \|` | Word 表格，首行为表头 |
| ` ``` ` 代码块 | 等宽段落 |
| `> 引用` | 引用样式 |
| `![说明](图.png)` | 居中图片 + 斜体图注 |
| 单独一行 `---` | **分页符** |

## 读已有文档

用户上传了 `.docx` 要你处理时，先 `read_docx.py` 读成 Markdown 再动手。
它同样能读 Word 存的 `.docx` 模板正文。

## 注意

- 图片路径必须在工作区内，越界会被拒绝。
- 不支持脚注、封面、分栏、修订痕迹。要这些就如实说做不到。
- 中文字体用文档默认，不做嵌入。
- 生成完**务必 read_docx 核对一遍**再回话。
