# 制作 PowerPoint

## 什么时候用

用户要一份**能打开、能放映**的 `.pptx`。只要提纲或文字内容的话不必走这套。

## 流程

1. **先写大纲**，用 `write` 存成工作区里的 `.md`。格式见下。内容先想清楚——脚本是一次性转换的。
2. **生成**：
   ```
   bash("python3 .skills/pptx/scripts/build_deck.py 大纲.md 输出.pptx")
   ```
   需要用户批准后才会执行。
3. **读回核对**（重要，二进制文件 `read` 看不了）：
   ```
   bash("python3 .skills/pptx/scripts/read_pptx.py 输出.pptx")
   ```
   它会按页打印标题、要点、表格、图表系列和备注。核对内容是否和你想要的一致。
4. **可选：渲染预览**，同时也验证文件真能被 Office 打开：
   ```
   bash("python3 .skills/pptx/scripts/thumbnail.py 输出.pptx")
   ```
   每页出一张 PNG 到 `thumbnails/`，用户可以在「文件」面板里下载来看。
5. **告诉用户文件名**，让他从右栏「文件」下载。

## 大纲格式

`---` 单独一行分页。每页第一个 `#` 是页标题。

```markdown
# 演示文稿标题
## 副标题

---

# 要点页
- 一级要点
  - 二级（缩进 2 格）
    - 三级（缩进 4 格）

> 讲者备注写在引用块里，不出现在幻灯片正文

---

# 表格页
| 列A | 列B |
|---|---|
| 值1 | 值2 |

---

# 图表页
```chart bar
类别,系列一,系列二
Q1,120,80
Q2,150,90
```

---

# 图片页
![说明文字](图片.png)

---

# 只有标题的页会排成分节页
```

**页型是按内容自动判断的**，不用额外指令：

| 这一页里有 | 排成 |
|---|---|
| 第一页且没有正文 | 封面页（`##` 作副标题） |
| 只有标题（非第一页） | 分节页 |
| 只有要点 | 标准要点页 |
| 表格 / 图表 / 图片 | 标题 + 手工排版页 |

图表类型：`bar`（默认）、`column`、`hbar`、`line`、`pie`。数据是 CSV，首行表头，
第一列是类别，其余列每列一个系列。

## 注意

- 每页要点控制在 6 条以内，超过脚本会警告但不会自动缩字号——自己拆页。
- 图片路径必须在工作区内，越界会被拒绝。
- 不支持自定义主题/母版。用户要企业模板时如实说做不到，不要假装做了。
- 生成完**务必 read_pptx 核对一遍**再回话。说"已生成"却没核对过，等于没做。
