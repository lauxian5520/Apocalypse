# 天启（Apocalypse）项目学习教程 · 导读

## 这份教程是给谁看的

这份教程假设你：

- 会写 Python / JavaScript，但没有系统做过 Web 全栈项目；
- 听说过「Agent」「Function Calling」「RAG」这些词，但没有亲手实现过一个完整的、可运行的 Agent 系统；
- 正在准备 **LLM Post-Train 算法工程师 / Agent 开发工程师** 方向的实习或校招面试，希望把这个开源项目讲清楚、讲深。

天启是一个部署在个人网站上的"知识空间"：博客 + 社交笔记 + AI 助手 + **Agent 工作台（Harness）**。
对求职这个方向而言，**Harness 子系统是全项目含金量最高的部分**——它不是调用一次 `openai.chat.completions.create()`
就完事的"套壳"，而是一个自己实现的、具备事件溯源（Event Sourcing）、工具调用循环、人工审批、沙箱执行、
上下文压缩、多智能体委派的**最小可用 Agent Runtime**。这正是 Claude Code、Cursor Agent、AutoGPT 这类产品
背后的核心机制的一个"教学级但生产可用"的实现。

## 阅读方式：定义 + 大白话

每一节涉及新概念时，会先给一个**严谨定义**（面试时可以直接照着说），再给一段**大白话解释**
（帮你真正理解、能举一反三）。例如：

> **严谨定义**：事件溯源（Event Sourcing）是一种持久化模式，系统不直接存储"当前状态"，而是存储
> 导致状态变化的一系列不可变事件；当前状态是这些事件按顺序重放（replay）后的派生结果。
>
> **大白话**：别存"结果"，存"过程"。你银行卡里现在有多少钱，不是数据库里存的一个数字被反复加减，
> 而是把每一笔转账、每一笔消费都记下来，"当前余额"是把这些流水从头加到尾算出来的。这样做的好处是：
> 出了问题可以查流水，还能"倒带"到任意一笔之前重新算一遍。
